PID 펌웨어 수정 계획
작성일: 2026-08-26
최종 수정일: 2026-08-27
작업 브랜치: 제어기에_펌웨어_개입

0. 목적

- 20℃ -> 40℃ 가열 응답은 기존 양산 펌웨어보다 개선한다.
- 40℃ -> 20℃ 냉각 후 장시간 진동을 0.15℃ P-P 이하로 낮춘다.
- 한 번에 하나의 제어 로직만 변경하여 효과와 부작용을 구분한다.
- CSV는 기존 40열을 유지하고, 꼭 필요한 경우에만 사용자 확인 후 변경한다.


1. 현재 기준 상태

1.1 펌웨어 기준

- 5~14차 가열·냉각 로그를 동일 기준으로 재비교한 결과 10차가 응답, 언더슈트/오버슈트 및 장시간 안정화의 종합 최적점이다.
- 10차 가열은 39.9℃ 도달 190.2초, 40℃ 도달 218.6초, 최고 PV 40.129℃, ±0.1℃ 연속 300초 안정화 397.5초였다.
- 10차 냉각은 90% 도달 121.3초, 최저 PV 19.804℃, ±0.1℃ 연속 300초 안정화 371.0초, 마지막 120초 0.042℃ P-P였다.
- 현재 작업 소스는 11~14차 변경을 모두 제거하고 검증된 10차 냉각 NEAR ±0.05℃ Ki 데드밴드 구조로 원복했다.

유지:

- HEATING 방향의 FAR -> NEAR 계수 전환 시 bumpless 적분 preload
- COOLING 방향의 작은 역가열 출력 차단
- COOLING 목표 1℃ 이내 냉각 출력 증가율 최대 2%/s
- 제한 후 Applied MV를 기존 back-calculation에 반영
- configured/effective 계수 및 제어 상태를 기록하는 CSV 40열

현재 작업 소스에만 존재:

- COOLING의 PLC configured FAR 6000/0/100을 effective 20000/0/1로 치환
- COOLING의 PLC configured NEAR 12000/2400/100을 effective 40000/600/1로 치환
- COOLING FAR(Ti=0) -> NEAR(Ti>0) 전환에서는 bumpless I preload를 생략하고 I=0에서 NEAR를 시작
- COOLING + effective NEAR 40000/600/1에서 |SV-PV| <= 0.05℃이면 오차에 의한 Ki 적분만 정지
- P/D 계산과 기존 back-calculation은 데드밴드 안에서도 계속 수행
- 최초 냉각 계산 전에는 유효한 이전 출력이 없으므로 bumpless preload를 수행하지 않는 보호 상태
- 위 치환은 COOL_CTRL_MODE이면서 COOLING 방향일 때만 적용
- COOLING FAR에서는 Ti=0으로 I를 사용하지 않고 P항에 따라 냉각 출력을 목표 접근 중 자연스럽게 감소

10차 원복으로 제거한 11~14차 항목:

- 11차 냉각 적분 정지/재개 0.05℃/0.10℃ 히스테리시스
- 12차 냉각 Ki 0.05~0.10℃ 선형 가중
- 13차 냉각 정상구간 0.1% 최소출력과 가열 저온측 Ki 강화
- 14차 냉각 NEAR Ti=120초와 가열 목표 도달 후 복구 게이트

미적용 또는 원복:

- HEATING+NEAR Ti=1200 강제 적용
- 냉각 NEAR D 필터 시정수 0.75초
- 4차에서 사용한 복합 conditional integration
- 4차에서 수행한 냉각 출력 증가율 제한 제거
- 방향별 PB/Ti 강제 변경
- SMPS 출력 변환식 변경

1.2 기준 PLC 설정

- alpha=20
- FAR=6000/0/100
- NEAR=12000/2400/100
- PLC FAR/NEAR 전환 방식은 그대로 사용한다.
- Td=100은 다음 장시간 기준시험을 위한 값이며 최종 확정값은 아니다.

1.3 냉각 출력 로직

작은 역가열 차단:

- COOLING 방향에서 작은 음수 MV는 실제 가열 출력으로 내보내지 않고 0으로 제한한다.
- PV <= SV-0.3℃이면 언더슈트 복구를 위해 역가열을 허용한다.
- PV >= SV-0.1℃이면 역가열을 다시 차단한다.
- Enable 진입 또는 SV 변경 시 허용 상태를 초기화한다.

냉각 출력 증가율 제한:

- 조건: COOLING이고 |SV-PV| <= 1.0℃
- 냉각 출력 증가: 최대 2%/s
- 냉각 출력 감소: 즉시 허용
- FAR 냉각과 전체 가열 운전에는 적용하지 않는다.

가열 bumpless:

- HEATING 방향에서 PLC Ti가 실제로 0에서 양수로 바뀔 때 한 번만 적용한다.
- 이전 Applied MV와 새로운 P/D항을 이용해 I를 preload한다.
- COOLING 방향에는 적용하지 않는다.

- 주의: Td=100 냉각 로그는 총 약 415초로 장시간 안정성 판정에 부족함

- 마지막 60초: 0.354℃ P-P
- 마지막 출력: 약 0~20W 냉각 펄스 반복
- 판단: 초기와 중기에는 Td=100보다 부드러웠지만 약 500~600초 이후 장주기 진동이 다시 커짐
- 결론: Td는 빠른 출력 흔들림에 영향을 주지만 장주기 진동의 근본 원인은 아님

2.5 4차 복합 변경시험

동시에 변경한 항목:

- D 필터 시정수 0.75초
- conditional integration
- 냉각 출력 증가율 제한 제거

결과:

- 냉각 21℃ 도달: 97.5초
- 냉각 20℃ 도달: 221.9초
- 마지막 60초: 0.379℃ P-P
- 최저 PV: 19.755℃
- 출력 펄스는 감소했지만 더 크고 느린 PV 진동으로 변경됨

판단:

- 4차 조합은 실패하여 전체 원복
- 세 항목을 동시에 변경했으므로 conditional integration 하나의 효과로 해석하지 않는다.
- 같은 조합을 다시 적용하지 않는다.


3. 다음 실행 계획

3.1 5차 수정: 냉각 I 바이어스 연속 유지

진행 판단:

- 같은 장비의 양산 PID는 냉각 정상상태에서 MV 약 0.1~0.4%와 SMPS 명령 약 2~7W를 연속 유지하며 마지막 60초 0.101℃ P-P를 기록했다.
- 현재 3차는 Applied MV가 0~1.9%를 반복하고 마지막 60초 0.216℃ P-P가 남았다.
- 현재 냉각은 FAR Ti=0이므로 접근 중 정상 냉각 바이어스를 학습하지 못하고, FAR -> NEAR 전환 시 MV가 약 15.4%에서 7.7%로 급락한다.
- NEAR Ti=240초는 떨어진 출력과 정상상태 바이어스를 복구하기에 지나치게 느리다.
- 고정 최소출력을 강제하지 않고 I항이 필요한 연속 냉각 출력을 학습하고 유지하게 하는 것을 5차의 단일 구조 가설로 한다.

기준 상태:

- 3차 펌웨어를 기준으로 한다.
- PLC configured 값은 alpha=20, FAR=6000/0/100, NEAR=12000/2400/100을 유지한다.
- 역가열 차단, 냉각 출력 증가율 2%/s, 가열 bumpless, SMPS 변환식과 CSV 40열을 유지한다.
- HEATING 방향은 변경하지 않는다.

5차 냉각 effective 계수의 최초 후보:

| 냉각 구간 | PLC configured PB/Ti/Td | 펌웨어 effective PB/Ti/Td |
|---|---|---|
| FAR | 6000/0/100 | 20000/50/1 |
| NEAR | 12000/2400/100 | 40000/60/1 |

환산 근거:

- 현재 PID의 Kp=100/PB 수식에서 effective PB=20000은 Kp 5%/℃, PB=40000은 Kp 2.5%/℃에 해당한다.
- effective Ti=50/60은 5/6초이며, 실제 양산 PID의 FAR/NEAR 적분 세기를 현재 단일 누적 I 수식으로 근사한 최초 후보이다.
- effective Td=1은 0.01초이며, 양산 PID의 작은 미분 보정 수준과 일치시킨다.
- 위 값은 PLC 값을 바꾸는 것이 아니라 COOLING 방향의 내부 effective 값으로만 적용한다.

5차 제어 동작:

1) COOLING 시작부터 FAR에서도 I항을 활성화하여 접근 중 필요한 냉각 바이어스를 학습한다.
2) PLC configured FAR/NEAR 전환을 감지하고 전환 직전 Applied MV를 저장한다.
3) 새로운 effective P/D항으로 다음 식을 계산하여 I를 preload한다.

   I_preload = 이전 Applied MV - 새로운 P항 + D항 보정

4) FAR -> NEAR와 NEAR -> FAR 모두 출력이 연속되도록 양방향 bumpless를 적용한다.
5) NEAR에서는 I가 평균 냉각 부하를 담당하고 P/D는 바이어스 주변의 작은 보정만 담당한다.
6) 고정 최소 냉각 출력 또는 강제 MV floor는 사용하지 않는다.
7) 평균 PV가 낮아지면 I 바이어스가 자연스럽게 감소하며, 실제 언더슈트 조건에서는 기존 역가열 허용 로직을 사용한다.

5차에서 변경하지 않는 항목:

- PLC 프로그램과 configured PB/Ti/Td 및 alpha
- HEATING effective 계수와 heating bumpless
- 역가열 히스테리시스 0.3℃/0.1℃
- 냉각 출력 증가율 2%/s
- SMPS 저출력 변환식
- CSV 40열

5차 구현 및 빌드 기록:

- 구현일: 2026-08-26
- 구현 파일: UserApp/Src/a_control.c
- 구 5차 적분 데드밴드 코드는 제거했다.
- COOLING FAR/NEAR configured 계수는 PLC와 CSV에 그대로 유지하고 PID 내부 EffectivePb/EffectiveTi/EffectiveTd만 위 후보값으로 바꾼다.
- FAR -> NEAR와 NEAR -> FAR 전환 모두 직전 Applied MV가 이어지도록 I를 preload한다.
- CL Disable, 시스템 정지 또는 새 SV 방향 판정 시 출력 유효 상태와 bumpless 대기 상태를 초기화한다.
- Debug main-build 성공: text 185164, data 26712, bss 30624 bytes
- Debug/CHPC-TCM1.hex: 596065 bytes
- SHA-256: B6BA95F8B006C7C059E7D32DA91CD17374EC21E8672CF3598D9F4831472BF5DF
- 기존 미사용 PID 함수 3건의 컴파일 경고만 있으며 새 오류는 없다.
- 루트 EXEC는 사용자 승인 전까지 갱신하지 않았다.

5차 목적:

- 정상 냉각 출력을 0%와 수 % 펄스로 만들지 않고 작은 양수 바이어스로 유지한다.
- 낮은 NEAR P/D로 열 지연에 대한 과잉보정을 줄인다.
- 빠른 I와 bumpless preload로 PB 증가에 따른 응답 지연 및 출력 급락을 방지한다.


3.2 5차 시험 및 판정

시험 조건:

- 20℃ -> 40℃ -> 20℃ 운전
- 배관 닫힘 및 기존과 동일한 장비 조건
- PLC FAR/NEAR 기준은 |SV-PV| 0.7℃를 사용한다.
- 냉각 목표 도달 후 최소 700초 기록한다.
- 새로운 CSV 열은 추가하지 않는다.

우선 확인할 동작:

- configured 계수는 PLC 값으로 유지되고 effective 계수만 COOLING에서 20000/50/1 및 40000/60/1로 바뀌는가
- FAR/NEAR 전환 직전과 직후 Applied MV가 연속적인가
- 정상상태 Applied MV가 작은 양수 범위에 머물고 0%를 반복 통과하지 않는가
- Calculated MV와 Applied MV 차이가 장시간 누적되지 않는가

확인값:

- 매 60초 PV 평균과 P-P
- Calculated MV 최소/최대
- Applied MV 최소/최대와 평균
- Applied MV가 0에 제한된 시간과 횟수
- SMPS 냉각 펄스 횟수와 출력 범위
- 21℃ 및 20℃ 도달시간
- FAR/NEAR 전환 전후 Applied MV 변화
- 최저 PV와 평균 정상상태 오차
- fault 및 usb_dropped_count

조기 실패 조건:

- 한 구간의 PV P-P가 0.30℃ 이상이면 즉시 종료한다.
- PV P-P가 0.20℃를 초과하고 다음 60초 구간에서도 유지되거나 증가하면 종료한다.
- Applied MV가 다시 0과 수 % 냉각 펄스를 반복하면서 PV 진폭도 증가하면 종료한다.
- FAR/NEAR 전환에서 Applied MV가 2%p 이상 불연속적으로 변하면 종료한다.
- 언더슈트가 19.75℃ 미만이면 종료한다.

5차 통과 기준:

- 후반 5개 연속 60초 구간이 모두 0.15℃ P-P 이하
- 평균 PV 편차가 ±0.10℃ 이내
- Applied MV의 반복적인 0% 고착과 냉각 펄스가 없어야 함
- 21℃ -> 20℃ 응답이 3차보다 느려지지 않아야 함
- fault 및 usb_dropped_count 증가 없음

5차 실제 결과 및 6차 진행 판단:

- 냉각 후반 300초 PV P-P는 0.078℃이고 평균 PV는 20.0006℃로 정상상태 안정성 목표를 통과했다.
- 후반 냉각 출력은 0.3~0.5%, SMPS 명령은 평균 3.89W로 유지됐으며 출력 0%, fault 및 usb drop은 없었다.
- 냉각 초기에 NEAR 진입 시 Applied MV가 99.9%였고 최초 20℃ 통과 시에도 98.9%였다.
- 최저 PV는 16.485℃이며 19.75℃ 미만이 약 53.6초 지속되어 언더슈트 기준으로 5차 전체 시험은 실패다.
- 후반 NEAR 구조는 유지하고 FAR 상한 포화 중 I 누적만 분리하여 6차 단독 변경으로 시험한다.
- 고정 최소출력과 NEAR Ti 변경은 6차에 포함하지 않는다.


3.3 6차 수정: 냉각 FAR 상한 포화 방향 적분 정지

목적:

- 냉각 FAR에서 출력이 상한에 붙어 있는 동안 I가 추가로 누적되어 FAR -> NEAR 전환 시 약 100% 출력이 유지되는 현상을 막는다.
- 5차에서 확보한 NEAR의 작은 연속 냉각 바이어스와 후반 안정성은 유지한다.

적용 조건:

- 운전 방향이 COOLING이다.
- 제어 모드가 COOL_CTRL_MODE이다.
- 현재 내부 effective 계수가 FAR 20000/50/1이다.
- Calculated MV가 출력 상한을 초과한다.
- 제어 오차가 냉각 출력을 더 증가시키는 방향이다.

동작:

- 위 조건이 모두 참일 때 오차에 의한 Ki 적분만 0으로 한다.
- 출력 상한에서 빠져나오는 방향의 오차 적분은 계속 허용한다.
- Calculated MV와 Applied MV 차이에 따른 기존 back-calculation은 항상 유지한다.

- 4차에서 사용한 복합 conditional integration 코드를 그대로 재사용하지 않는다.
- 이 단계에서도 다른 로직을 동시에 변경하지 않는다.

3.16 보류 후보: Td 최종 선택

진행 조건:

- 적분 및 출력 제한 로직이 확정된 뒤 진행한다.

비교:

- FAR/NEAR의 Td는 함께 변경한다.
- 명확한 실패는 조기 종료하고, 안정적으로 보이는 조건만 동일한 장시간 데이터로 최종 비교한다.

- 20℃ 도달시간

- 언더슈트

현재 Td=100은 3차 기준값이며, 5차 최초 후보의 cooling effective Td는 1이다.


4. 시험 및 변경 원칙

- 한 시험에서는 한 항목만 변경한다.
- 5차의 effective P/I/D 변환과 I 바이어스 연속성 및 bumpless는 서로 분리하면 출력 급락 또는 과잉보정이 남으므로 하나의 구조 변경 묶음으로 취급한다.
- 현재 기준선은 10차이며 재검증 완료 전에는 추가 제어 변경을 적용하지 않는다.
- 가열 변경과 냉각 변경은 같은 HEX에 동시에 포함하지 않는다.
- 11~14차 실패 로직은 새 원인 근거 없이 다시 적용하지 않는다.
- 새 변경은 10차 대비 코드 한 항목, 로그 한 방향, 판정 기준 한 세트로 분리한다.
- 명확한 진동이 보이는 시험은 조기 종료하고, 안정적인 후보만 장시간 검증한다.
- 배관, 밸브, 부하, 로그 주기 및 운전 절차를 동일하게 유지한다.
- 시험 중 진동이 커져 안전 한계를 위협하면 즉시 Disable한다.
- 결과가 나쁜 변경은 해당 변경만 원복한다.
- 사용자 승인 없이 루트 EXEC를 갱신하지 않는다.
- 펌웨어 리비전은 0x0005를 유지한다.
- PC 프로그램 변경을 피하기 위해 CSV 40열을 유지한다.
