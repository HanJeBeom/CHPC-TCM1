PID 펌웨어 수정 계획
작성일: 2026-08-26
작업 브랜치: 제어기에_펌웨어_개입

0. 한 줄 요약

- 가열은 PLC 계수를 그대로 사용하고, FAR에서 NEAR 계수로 바뀌는 순간에만 적분값을 preload하여 출력 급락을 막는다.
- 냉각은 계수를 바꾸지 않고, 목표 부근의 역가열 반복과 급격한 냉각 출력 상승을 펌웨어에서 제한한다.
- PLC 프로그램과 PLC 설정값은 변경하지 않는다.


1. 현재 상태

1.1 PLC 설정값

- alpha: 20
- FAR: PB=6000, Ti=0, Td=100
- NEAR: PB=12000, Ti=2400, Td=100
- PLC의 FAR/NEAR 전환 방식은 그대로 사용한다.

1.2 1차 가열 수정 이력

- SV 변경 시 운전 방향을 HEATING 또는 COOLING으로 저장한다.
- 펌웨어 진단용 FAR/NEAR 기준:
  - FAR -> NEAR: |SV-PV| <= 1.0℃
  - NEAR -> FAR: |SV-PV| >= 1.3℃
- HEATING+NEAR에서만 effective Ti=1200을 사용한다.
- 그 외에는 PLC가 보낸 configured Ti를 그대로 사용한다.
- PB와 Td는 펌웨어에서 변경하지 않는다.

3차 변경 사항:

- 1차의 HEATING+NEAR effective Ti=1200 강제 적용은 제거한다.
- 3차부터 모든 effective PB/Ti/Td는 PLC configured 값과 같게 사용한다.
- 가열 속도는 계수 강제 변경 대신 4장의 heating bumpless 적분 전환으로 개선한다.

1.3 1차 시험 결과

- 가열 시작 -> 39℃: 84.2초
- 가열 39℃ -> 39.9℃: 178.1초
- 가열 39℃ -> 40℃: 241.4초
- 가열 최대 온도: 40.068℃
- 가열 마지막 60초 PV 진동폭: 0.053℃ P-P
- 냉각 마지막 60초 PV 진동폭: 0.623℃ P-P
- fault: 없음
- USB drop: 없음

판단:

- 가열 개선은 효과가 있으므로 유지한다.
- 냉각 진동은 해결되지 않았으므로 2차 수정이 필요하다.

1.4 2차 시험 결과

- 가열 39℃ -> 39.9℃: 203.6초
- 가열 39℃ -> 40℃: 261.8초
- 가열 최대 온도: 40.075℃
- 가열 마지막 60초 PV 진동폭: 0.036℃ P-P
- 냉각 마지막 60초 PV 진동폭: 0.284℃ P-P
- 냉각 마지막 300초 PV 진동폭: 0.304℃ P-P
- 냉각 출력 최대 상승률: 약 13.73%/s
- 역가열 차단 샘플: 399개
- fault 및 USB drop: 없음

판단:

- 역가열 차단으로 냉각 진동은 1차 0.623℃에서 약 절반으로 감소했다.
- 목표 0.15℃ P-P에는 미달하며 빠른 냉각 출력 재상승이 남아 있어 3차 출력 증가율 제한이 필요하다.


2. 최종 제어 동작

| 운전 상태 | PLC configured PB/Ti/Td | 펌웨어 effective PB/Ti/Td |
|---|---|---|
| HEATING+FAR | 6000/0/100 | 6000/0/100 |
| HEATING+NEAR | 12000/2400/100 | 12000/2400/100 |
| COOLING+FAR | 6000/0/100 | 6000/0/100 |
| COOLING+NEAR | 12000/2400/100 | 12000/2400/100 |

추가 출력 로직:

- HEATING: 냉각용 출력 제한은 적용하지 않고, 실제 Ti 0->양수 전환 시 한 번만 bumpless 적분 preload를 적용한다.
- COOLING: 아래 3장의 역가열 차단 및 출력 증가율 제한을 적용한다.


3. 냉각 수정 항목

3.1 작은 역가열 출력 차단

목적:

- 냉각 목표 부근에서 SMPS가 냉각과 가열 극성을 반복 전환하는 현상을 막는다.

동작:

1) COOLING 방향에서는 작은 음수 MV를 바로 가열 출력으로 내보내지 않고 0으로 제한한다.
2) PV <= SV-0.3℃가 되면 실제 언더슈트 복구를 위해 역가열을 허용한다.
3) 역가열 허용 후 PV >= SV-0.1℃까지 회복하면 다시 역가열을 차단한다.
4) Enable 진입 또는 SV 변경 시 역가열 허용 상태를 초기화한다.

히스테리시스:

- 역가열 허용: PV <= SV-0.3℃
- 역가열 차단: PV >= SV-0.1℃


3.2 냉각 출력 증가율 제한

목적:

- 목표 부근에서 냉각 출력이 0%에서 수 %까지 급격히 반복 상승하는 현상을 막는다.

적용 조건:

- direction == COOLING
- |SV-PV| <= 1.0℃

동작:

- 냉각 출력 증가: 최대 2%/s
- 냉각 출력 감소: 제한하지 않고 즉시 허용
- 원거리 냉각: 적용하지 않음
- 전체 가열 운전: 적용하지 않음
- Enable 진입 또는 SV 변경 시 이전 실제 MV 상태를 초기화함


3.3 anti-windup 연동

적용 순서:

1) PID가 MV를 계산한다.
2) 기존 출력 상한과 하한을 적용한다.
3) 냉각 역가열 차단을 적용한다.
4) 냉각 출력 증가율 제한을 적용한다.
5) 최종 제한 MV를 실제 출력으로 사용한다.
6) PID 계산 MV와 최종 제한 MV의 차이를 기존 back-calculation에 반영한다.

목적:

- 출력이 제한되는 동안 적분값이 뒤에서 계속 쌓이는 현상을 방지한다.
- 제한 해제 순간 MV가 튀는 현상을 방지한다.


4. 3차 가열 bumpless 적분 전환

4.1 목적

- PLC FAR 계수 6000/0/100에서 NEAR 계수 12000/2400/100으로 바뀔 때 P 출력 감소와 I=0으로 인한 MV 급락을 방지한다.
- 펌웨어가 가열 Ti를 별도 값으로 강제하지 않고 PLC configured 계수를 그대로 사용한다.

4.2 적용 조건

- 저장된 운전 방향이 HEATING이다.
- PLC configured Ti가 실제로 0에서 양수로 변경된다.
- 조건이 성립한 계수 변경 직후 첫 PID 계산에서 한 번만 적용한다.
- 펌웨어 진단용 FAR/NEAR 상태만으로는 적용하지 않는다.
- COOLING 방향에는 적용하지 않는다.

4.3 동작

1) 계수 전환 직전 최종 Applied MV를 저장한다.
2) PLC가 전달한 새로운 PB/Ti/Td로 P항과 D항을 계산한다.
3) 다음 식으로 적분값을 preload한다.

   I_preload = 이전 Applied MV - 새로운 P항 + D항 보정

4) I_preload는 기존 출력 상한과 하한 범위로 제한한다.
5) 전환 직후 MV가 이전 Applied MV와 연속되도록 한다.
6) 그다음 제어 주기부터 PLC Ti=2400으로 정상 적분한다.

4.4 변경하지 않는 항목

- PLC 프로그램
- PLC 설정 화면
- PLC configured PB/Ti/Td 및 alpha
- PB와 Td 계산
- SP 필터와 alpha 처리
- SMPS 출력 변환식
- 기존 출력 상한과 하한
- 배관·밸브 운전 순서
- 가열 출력 경로


5. CSV 진단 요구사항

CSV 변경 원칙:

- 현재 40열 형식을 기본 고정 사양으로 유지한다.
- 이후 제어 로직을 수정해도 기존 로그 값으로 판정할 수 있으면 CSV 열을 추가·삭제·변경하지 않는다.
- 새로운 로그 필드는 원인 확인이 불가능한 경우에만 검토한다.
- CSV 형식 변경이 꼭 필요하면 펌웨어 수정 전에 사용자 확인을 받고, PC 프로그램 변경 요구사항도 함께 작성한다.
- 일회성 시험을 위한 임시 로그 열 추가는 지양한다.

다음 값을 기록한다.

- configured_pb/ti/td
- effective_pb/ti/td
- configured_alpha
- effective_alpha
- control_direction_u16
  - 0=HEATING
  - 1=COOLING
- pid_region_u16
  - 0=FAR
  - 1=NEAR
- pid_params_pending
- PV
- PID 계산 MV
- 최종 제한 MV
- SMPS 출력 명령
- fault
- usb_dropped_count

CSV로 확인할 사항:

- 가열과 냉각 모두 configured PB/Ti/Td와 effective PB/Ti/Td가 같은가
- 가열 Ti 0->양수 전환 직후 Applied MV가 비정상적으로 떨어지거나 튀지 않는가
- 냉각 목표 부근에서 음수 MV가 반복 출력되지 않는가
- 냉각 출력 상승 변화율이 최대 2%/s 이하인가
- 제한 동작 중 적분 누적으로 인한 MV 급변이 없는가


6. 단계별 구현 및 시험 순서

두 냉각 로직은 한꺼번에 적용하지 않는다. 효과와 부작용을 구분하기 위해 아래 순서로 진행한다.

6.1 2차 수정: 역가열 차단만 적용

1) 현재 브랜치와 기준 커밋을 기록한다.
2) CSV 진단 필드를 추가하거나 복구한다.
3) 3.1의 작은 역가열 출력 차단만 구현한다.
4) 제한된 최종 MV가 back-calculation에 반영되도록 한다.
5) 3.2의 냉각 출력 증가율 제한은 아직 적용하지 않는다.
6) 가열 경로가 1차 수정과 동일한지 정적으로 확인한다.
7) 빌드 후 20℃ -> 40℃ -> 20℃ 시험을 수행한다.
8) 가열 성능과 냉각 진동폭을 1차 결과와 비교한다.

2차 판정:

- 냉각 P-P가 0.15℃ 이하이면 역가열 차단만 채택하고 3차 수정은 하지 않는다.
- 냉각 진동이 충분히 줄지 않으면 CSV에서 역가열 차단 동작을 확인한 뒤 3차로 진행한다.
- 평균 PV 편차 또는 언더슈트가 커지면 3차로 가지 않고 역가열 허용 기준부터 조정한다.

6.2 3차 수정: 냉각 출력 증가율 제한 및 가열 bumpless 적용

2차 수정만으로 냉각 진동이 충분히 줄지 않을 때만 진행한다.

1) 2차 수정 상태를 기준으로 3.2의 출력 증가율 제한을 추가한다.
2) COOLING이고 |SV-PV| <= 1.0℃일 때만 냉각 출력 증가를 최대 2%/s로 제한한다.
3) 냉각 출력 감소는 즉시 허용한다.
4) 최종 제한 MV를 back-calculation에 반영한다.
5) HEATING+NEAR effective Ti=1200 강제 적용을 제거한다.
6) 가열 configured Ti가 0에서 양수로 바뀔 때만 4장의 I preload를 한 번 적용한다.
7) 냉각에는 I preload를 적용하지 않는다.
8) CSV는 현재 40열 형식을 변경하지 않는다.
9) 같은 조건으로 20℃ -> 40℃ -> 20℃ 재시험을 수행한다.
10) 가열 로그와 냉각 로그를 각각 비교하여 두 변경의 효과를 구분한다.

3차 판정:

- 냉각 P-P가 0.15℃ 이하이고 냉각 응답 지연이 크지 않으면 채택한다.
- 가열 계수 전환 직후 Applied MV가 연속적이고 마지막 1℃ 응답이 개선되면 bumpless를 채택한다.
- 가열 오버슈트가 증가하면 preload 제한 범위를 먼저 조정한다.
- 냉각이 느려지면 증가율을 2%/s에서 3%/s로 완화하는 시험을 검토한다.
- 진동 억제가 부족하면 적용 범위를 |SV-PV| <= 1.0℃에서 더 넓히지 말고, 실제 MV와 SMPS 명령의 동작부터 확인한다.

6.3 공통 마무리

1) STM32CubeIDE Debug 빌드로 ELF와 HEX를 생성한다.
2) 빌드 경고, HEX 크기와 SHA-256을 기록한다.
3) 사용자 확인 전에는 루트 EXEC를 갱신하지 않는다.


7. 재시험 조건

PLC 설정:

- alpha=20
- FAR=6000/0/100
- NEAR=12000/2400/100

시험 순서:

1) 20℃ -> 40℃ 가열
2) 40℃ -> 20℃ 냉각
3) 냉각 목표 도달 후 최소 700초 이상 유지
4) 기존과 같은 장비 조건, 로그 주기 및 운전 절차 사용


8. 판정 기준

8.1 가열

- 2차 결과보다 마지막 1℃ 응답이 개선되어야 한다.
- 39℃ -> 39.9℃ 목표: 180초 이하
- 39℃ -> 40℃ 목표: 240초 이하
- 오버슈트가 과도하게 증가하지 않아야 한다.
- 정상상태 P-P가 0.1℃ 이하이어야 한다.

8.2 냉각

- 정상상태 PV P-P 목표: 0.15℃ 이하
- 기존 1차 결과 0.623℃ P-P보다 뚜렷하게 감소해야 한다.
- 목표 부근에서 불필요한 SMPS 극성 반복 전환이 없어야 한다.
- 출력 제한 동작 중 냉각 출력 상승 변화율이 2%/s 이하이어야 한다.
- 냉각 출력 감소는 지연되지 않아야 한다.
- 평균 PV가 SV에서 지속적으로 벗어나지 않아야 한다.

8.3 공통

- fault가 발생하지 않아야 한다.
- usb_dropped_count가 증가하지 않아야 한다.
- configured/effective 값이 설계한 조건과 일치해야 한다.
- FAR/NEAR 전환 시 비정상적인 MV 점프가 없어야 한다.


9. 전체 진행 순서 요약

1) 완료: 가열 HEATING+NEAR effective Ti=1200 적용 및 1차 시험.
2) 완료: 냉각 작은 역가열 차단 적용 및 2차 시험.
3) 2차 냉각 P-P 0.304℃로 목표에 미달하여 3차 진행.
4) 3차: 냉각 출력 증가율 2%/s 제한 추가.
5) 3차: 가열 Ti 강제 변경을 제거하고 가열 Ti 0->양수 전환에 bumpless I preload 적용.
6) 3차 시험 후 냉각 P-P와 가열 마지막 1℃ 응답을 각각 판정.
7) 냉각이 느려지면 증가율 제한을 3%/s로 완화하는 시험 검토.
8) 언더슈트나 평균 편차가 커지면 역가열 허용/차단 기준 조정.
9) 위 단계가 끝나기 전에는 SP 필터, 방향별 PB, Td 및 SMPS 변환식을 변경하지 않는다.


10. 보류 중인 후속 계획 보존 목록

아래 항목은 현재 단계에서 적용하지 않지만 삭제하지 않는다.
2차와 3차 시험으로 목표를 달성하지 못했을 때 한 항목씩 검토한다.
여러 항목을 동시에 적용하지 않으며, 시험 결과가 나온 항목은 삭제하지 않고 결과와 함께 상태만 변경한다.

10.1 가열 응답 후속 후보

1) HEATING+NEAR effective Ti 추가 조정
   - 1차와 2차 적용값: 1200
   - 3차에서는 강제 적용을 제거하고 PLC configured Ti=2400을 사용
   - 가열 개선이 부족하고 오버슈트가 작을 때: 800 시험 검토
   - 가열 진동 또는 오버슈트가 증가할 때: 1200보다 큰 값으로 복귀하거나 가열 Ti 개입 철회

2) 방향별 effective PB 적용
   - PLC가 가열과 냉각 계수를 구분하지 못할 때 펌웨어 내부에서만 검토
   - 가열 속도 향상이 필요하지만 냉각 진동 때문에 전체 PB를 낮출 수 없을 때 사용하는 후속안
   - 현재 가열 성능이 충분하므로 우선 적용하지 않음

3) 가열 SP 필터 조정 또는 우회
   - alpha와 Ti에 의한 SP_ref 지연이 실제 로그에서 다시 확인될 때만 검토
   - 과거 가열 effective alpha=0 시험에서는 이 운전 흐름의 응답 개선 효과가 명확하지 않았으므로 낮은 우선순위로 보존

10.2 냉각 진동 후속 후보

1) 역가열 히스테리시스 조정
   - 기본값: 허용 SV-0.3℃, 차단 SV-0.1℃
   - 언더슈트 또는 정상상태 평균 오차가 커질 때 가장 먼저 조정

2) 냉각 출력 증가율 조정
   - 기본값: 목표 부근 2%/s
   - 냉각 응답이 느릴 때: 3%/s 완화 시험
   - 진동 억제가 부족할 때: 제한의 실제 작동 여부를 먼저 확인한 후 적용 범위 조정 검토

3) conditional anti-windup
   - 출력 포화 방향으로 오차가 더 밀어붙일 때 적분 누적 정지
   - 반대 방향 오차는 적분 해소를 위해 허용
   - 기존 back-calculation만으로 제한 중 적분 누적을 충분히 막지 못할 때 검토

4) FAR/NEAR 계수 전환 bumpless 처리
   - 가열 Ti 0->양수 전환에 한해 3차 적용
   - 냉각에는 적용하지 않음
   - 계수 전환 시 현재 출력이 유지되도록 적분 상태 역산

5) 적분 데드밴드
   - 목표 부근의 작은 오차로 적분 방향이 계속 바뀌는 것이 확인될 때 검토
   - 정상상태 평균 오차가 남을 수 있으므로 역가열 차단과 출력 증가율 제한보다 후순위

6) 출력 극성 전환 지연 또는 확인 시간
   - 과거 후보: 냉각 NEAR에서 약 0.2℃ 조건 및 15초 확인
   - 단순 역가열 차단 히스테리시스로 극성 반복이 해결되지 않을 때 검토

7) 방향별 냉각 effective PB/Ti/Td
   - PLC 설정은 그대로 두고 COOLING+NEAR에만 별도 effective 계수를 적용하는 방안
   - 출력 제한만으로 해결되지 않을 때 검토
   - 기존 냉각 근거리 후보값 12000/2400/100을 기준으로 한 항목씩 변경

10.3 최후순위 출력단 후보

1) SMPS 저출력 구간 변환식 조정
   - 과거 5~10% 출력 선형 연결 시험은 냉각 진동 개선 효과가 명확하지 않았음
   - PID 최종 MV는 안정적인데 실제 SMPS 명령 또는 온도만 진동할 때 재검토

2) 최소 출력 또는 출력 데드밴드
   - 작은 출력 명령이 실제 장비에서 불연속적으로 작동하는 것이 확인될 때 검토
   - 정상상태 오차와 응답 지연을 만들 수 있으므로 후순위

3) 모델 기반 지연 보상
   - 배관 지연과 열관성이 계수 및 단순 출력 제한으로 해결되지 않을 때만 검토
   - 구현 복잡도와 검증 범위가 크므로 최후순위

10.4 초기화 관련 보존 항목

- Enable 진입 및 SV 변경 시 SP_prev, SP_ref_prev, PV_prev를 현재 PV로 초기화하는 최소 이력 초기화는 유지 후보로 보존한다.
- 적분값 I=0 강제 초기화는 과거 시험에서 지속 냉각 진동 해결 효과가 없었으므로 현재 적용하지 않는다.
- 필요 시 초기 과도응답 문제와 정상상태 진동 문제를 구분하여 다시 검토한다.

10.5 보존 원칙

- 위 후보는 계획 문서에서 삭제하지 않는다.
- 적용하지 않은 항목은 '보류', 시험한 항목은 '효과 있음/없음', 채택한 항목은 '적용'으로 표시한다.
- 현재 단계가 실패하면 바로 여러 로직을 넣지 않고 목록 순서와 CSV 근거에 따라 하나씩 적용한다.
